Before you upload

  1. Clean the project

    Delete build output to keep the file small, for example app/build, build and .gradle in an Android Studio project, or build in a Flutter project.

  2. Compress the whole project folder

    Make one .zip file containing the full project folder. Do not use .rar or .7z.

  3. Name the file with your registration number

    Use the helper below to get the exact file name.

  4. Check it, then upload

    Open the .zip once to make sure it extracts, then use the upload button above.
